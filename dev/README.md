# dev —— 构建产物

> ⚠ **本目录由 CI 自动生成**（每次构建会被整体覆盖），请勿手工修改。

这里存放 GitHub Actions 自动构建出的 Windows 安装包：

| 文件 | 说明 |
| --- | --- |
| `视频展台-<版本>-x64.msi` | MSI 安装包（WiX v4），适合企业批量部署 / 组策略 / 静默安装 |
| `视频展台-<版本>-x64-setup.exe` | EXE 安装包（Inno Setup 6），适合个人用户，向导更友好 |

**为什么要提交进仓库？**
GitHub 的 Actions Artifacts 需要登录才能下载；放进仓库后，
任何人（包括手机浏览器、未登录状态）都能直接点开下载。

**其它分发渠道**

| 需求 | 去处 |
| --- | --- |
| 历史版本 / 干净的发布页 | 仓库的 **Releases** 页面（打 `v*` tag 时自动创建） |
| 便携版（解压即用，含完整运行时目录） | Actions → 最新 run → **Artifacts → 视频展台-便携版** |

> 便携版体积 200 MB+ 且包含 300 多个文件，不适合入库，因此不在本目录提供。
